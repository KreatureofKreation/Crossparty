Crossparty

An unofficial Linux app for Xbox party chat. This is its own Flatpak repository, signed by the release workflow on GitHub. Not affiliated with, endorsed by, or sponsored by Microsoft.

Install

flatpak install --user @SITE_URL@/crossparty.flatpakref

Updates then come with every other Flatpak, from Discover or flatpak update.

Signing key

Every release is signed with this key, fingerprint @FINGERPRINT@. It is also in the source repository, in data/release-signing.asc.
